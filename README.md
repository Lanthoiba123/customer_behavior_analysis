# 📊 Data Analytics Project

## Overview

End-to-end data analytics project covering data cleaning, EDA, SQL analysis, Power BI dashboard development, and business reporting.

## Dataset

The dataset was analyzed to identify trends, patterns, and key business insights.

## Tools Used

* Python - Pandas
* SQL - PostgreSQL 
* Power BI
* GitHub

## Project Steps

1. Load dataset using Python.
2. Perform EDA and understand the data.
3. Clean and transform the data.
4. Load data into SQL database.
5. Write SQL queries for analysis.
6. Build an interactive Power BI dashboard.
7. Prepare a project report.

## Dashboard

The Power BI dashboard contains KPIs, trends, charts, filters, and key business metrics.

## Results

The analysis identified important trends, performance patterns, and business insights to support data-driven decision-making.

## How to Run

1. Clone the repository.
2. Open the Python notebook and run the EDA/cleaning steps.
3. Load the cleaned data into PostgreSQL.
4. Run the SQL queries.
5. Open the Power BI `.pbix` file.
6. Review the report and presentation.
